# Autonomous Data Scientist

Production-grade autonomous data science platform.

## Features

- Project and dataset management
- CSV / Parquet / JSON / JSONL upload
- Redis-backed analysis queue
- LangGraph analysis workflow
- Langfuse observability
- NeMo Guardrails safety checks
- FastAPI backend
- React + Vite frontend
- Docker Compose local stack

## Quick start

```bash
cp .env.example .env
docker compose up --build
